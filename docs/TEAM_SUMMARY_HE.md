# תקציר לצוות: Retro Rides (Smart Parking Tracker)

קראו את זה לפני שאתם נוגעים בקוד. 5 דקות והכל ברור.

## מה בנינו?

חניון חכם **לרכבי אספנות**. מצלמת IoT בכניסה מצלמת את לוחית הרישוי של כל רכב ושומרת את התמונה בשרת אחסון. השומר פותח לוח בקרה (דאשבורד) ורואה בזמן אמת את כל הרכבים בחניון, כמה זמן כל אחד חונה, וכמה הוא חייב.

בחרנו **מסלול 1 (Lite)**: בלי Backend ובלי Redis. שני שרתים בלבד, שמורצים עם Docker Compose.

## איך זה עובד? (3 שלבים)

1. המצלמה שומרת תמונה בשם `20261109-203015_MUSTANG-65.png` (תאריך, שעה ב-UTC, לוחית). **שעת הכניסה נמצאת בשם הקובץ.**
2. שרת **Apache** (`storage`) שומר את התמונות ומציג את התיקייה כדף אינטרנט.
3. שרת **Nginx** (`web`) מציג את הדאשבורד. ה-JavaScript שלו מבקש מ-Apache כל 3 שניות "יש תמונות חדשות?", ובונה כרטיס לכל רכב. תמונה חדשה בתיקייה = רכב חדש על המסך, בלי רענון.

התמונות נשמרות ב-**Volume** של Docker, אז גם אם מוחקים את כל הקונטיינרים, הרכבים נשארים.

## מה הרכיב האישי שלנו?

חניון רכבי אספנות בסגנון שנות ה-50: הודעה מצחיקה לכל רכב שנכנס, מחיר לפי שעות (12 ש"ח לשעה שהתחילה, 10 דקות ראשונות חינם), התראת **חניון מלא** (6 מקומות), כפתור **שחרור רכב**, **Dark Mode**, צפירה אופציונלית, ו-**Easter Egg**: מקלידים `vroom` בדאשבורד ורכב חוצה את המסך.

## איך מריצים? (3 פקודות)

```
docker compose up --build        # מפעיל הכל, ואז נכנסים ל-http://localhost:8080
.\scripts\camera.ps1             # (בטרמינל שני) רכב חדש נכנס לחניון
docker compose down              # ואז: docker compose up -d  ← הרכבים עדיין שם!
```

הפקודה `docker compose down -v` מוחקת גם את ה-Volume, וזה היחיד שמאפס את החניון.

## 8 שאלות Code Review שכדאי לדעת לענות עליהן

1. **למה אין `ports` ל-storage?** כדי שרק Nginx (באותה רשת) יגיע ל-Apache, מבחוץ אי אפשר.
2. **איך Nginx מוצא את Apache?** לפי שם השירות `storage`. ה-DNS הפנימי של Docker מתרגם אותו ל-IP.
3. **מה ההבדל בין `down` ל-`down -v`?** `down` מוחק קונטיינרים ורשת, אבל ה-Volume נשאר. `-v` מוחק גם אותו.
4. **למה `depends_on` עם `service_healthy`?** `depends_on` רגיל מחכה רק שהקונטיינר *יתחיל*, ה-healthcheck מוודא שהוא באמת *מוכן*.
5. **למה שעת הכניסה בשם הקובץ ולא בתאריך השינוי של הקובץ?** תאריך שינוי משתנה כשמעתיקים קבצים, השם נשאר.
6. **מה זה `GITHUB_TOKEN`?** טוקן אוטומטי שנוצר לכל הרצה של ה-Workflow. משתמשים בו להתחברות ל-`ghcr.io` בלי לשמור סיסמה. צריך `permissions: packages: write`.
7. **איך נוצרים תגיות הגרסה?** `docker/metadata-action`. אם דוחפים תג `v1.2.0` מקבלים `1.2.0` ו-`1.2`, ובנוסף `sha-<commit>`, `build-<מספר>` ו-`latest` ל-main.
8. **למה אין עוד התחלה כפולה של 4 הרכבים אחרי `down` ו-`up`?** סקריפט `entrypoint.sh` מכניס אותם רק אם ה-Volume ריק.

תשובות מלאות ומפורטות: `docs/CODE_REVIEW_PREP.md` (באנגלית, בנוי כך שאפשר לקרוא בקול רם).
